# FootQuant

FootQuant is a Windows desktop application for mathematical
football predictions and statistical analysis.

## Download

Download the latest Windows installer from the
[Releases page](https://github.com/godfreytshehla/FootQuant---Football-predictions/releases/latest).

## Installation

Download and run FootQuant-Setup-1.0.0.exe.

## Uninstallation

Windows Settings > Apps > Installed apps > FootQuant > Uninstall.
