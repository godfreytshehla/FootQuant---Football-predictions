# FootQuant

FootQuant is a Windows desktop application for mathematical
football predictions and statistical analysis.

## Download

Download the latest Windows installer from the
[Releases page](https://github.com/godfreytshehla/FootQuant---Football-predictions/releases/latest).

## Installation

Download and run FootQuant-Setup-1.0.0.exe.

## Uninstallation

Windows Settings > Apps > Installed apps > FootQuant > Uninstall.

## Feedback and Suggestions

FootQuant is continuously evolving, and your feedback is highly appreciated.

After trying the application, please share your thoughts on:

- **Suggestions:** Features or functionality you would like to see.
- **Improvements:** Areas that could be more accurate, efficient or user-friendly.
- **Bugs:** Any errors, crashes or unexpected behaviour.
- **User experience:** Your experience with the interface, navigation and overall performance.
- **Prediction quality:** Observations about the mathematical predictions and their usefulness.

Please submit your feedback through [GitHub Issues](https://github.com/godfreytshehla/FootQuant---Football-predictions/issues).

When reporting a problem, include the steps to reproduce it and any relevant error messages.

**All constructive feedback is welcome and will help guide future versions of FootQuant.**
